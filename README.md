# Mesto

Проектная работа Яндекс Практикума «Mesto»: сервис, в котором можно делиться фотографиями мест, ставить лайки и смотреть статистику карточек. Данные пользователя и карточек хранятся на сервере и загружаются через API.

## Функциональность

- загрузка профиля и карточек с сервера;
- редактирование профиля и обновление аватара;
- добавление карточек и удаление своих карточек с подтверждением;
- лайки со счётчиком;
- статистика карточек по клику на логотип: число пользователей, всего лайков, чемпион лайков и самые популярные карточки;
- валидация всех форм и индикация загрузки на кнопках.

## Технологии

HTML, CSS (БЭМ), JavaScript (ES-модули), Fetch API, Vite.

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера разработки (страница откроется в браузере автоматически):

```bash
npm run dev
```

Сборка проекта в директорию `dist`:

```bash
npm run build
```

Публикация собранного проекта на GitHub Pages:

```bash
npm run deploy
```
